First-time setup (GitHub token)
This page needs a GitHub Personal Access Token to save changes to your repo — it's stored only in your browser, never sent anywhere except GitHub.

How to create one:
1. Go to github.com/settings/tokens?type=beta
2. Click "Generate new token"
3. Name it "Chapati counter", set expiration (e.g. 90 days)
4. Under "Repository access", select "Only select repositories" → choose Chapati-Challenge-
5. Under "Permissions" → "Repository permissions" → set Contents to "Read and write"
6. Click "Generate token" and copy it
7. Paste it below once, then click Save — this browser will remember it
